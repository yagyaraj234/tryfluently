## Security boundaries assessed

Session/email verification protects custom API routes. DB reads/writes bind Learner IDs; tests cover cross-account Lessons, Goals, history, recordings, Focus Items and live-call targets. Completion holds Learner locks and commits learning results atomically, with rollback and concurrent-completion regressions. AI/audio credentials stay in server adapters; raw Goal Context is omitted from responses and audio uploads are not persisted. Auth deletion requires credentials/fresh sessions as appropriate, ends active calls, and cascades owned rows. Browser writes now have explicit Origin checks and chat/upload inputs have bounded shapes/sizes.
